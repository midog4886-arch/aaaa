<analysis>**original_problem_statement:**
We want to design a management program for a sports academy that includes the following activities: swimming, football, karate, and gymnastics.
(Academy Name: World Champions Performance Academy)

The program should briefly include:
- A system for recording subscriber data (name, age, guardian, mobile number, activity, schedules, subscription status, notes).
- Issuing invoices and subscription fees for each player with the ability to print or send them electronically, with the currency used being the Saudi Riyal (SAR).
- Monitoring subscription start and end dates with alerts before the subscription expires.
- The ability to send group and individual messages to subscribers or guardians via WhatsApp (payment reminders, subscription expiration, offers, or alerts). It is preferable to link the system with the WhatsApp Business API or any official approved solution for automated sending.
- The ability to segment subscribers by activity, group, or coach for easy targeting with messages and reports.
- Periodic financial reports on revenues (daily, monthly, annual) by activity, coach, or period.

Please clarify:
- The proposed technology or platform for developing the system (web/desktop application/mobile).
- I prefer a modern design with active sports colors suitable for a sports academy (such as shades of blue, green, or orange), with a simple and easy interface for the receptionist and coaches.
- The system needs to support both Arabic and English (a basic Arabic interface with the ability to switch to English), as some coaches or users may prefer English.

**Subsequent User Requests:**
- Allow a member to be linked to more than one sports activity at the same time. Each activity should have its own fees, start/end date, and subscription status (active, expired, frozen). Invoices should detail each activity.
- Manage all member subscription details from the invoice creation screen, not just the member addition screen.
- Add an Export to Excel feature for members, invoices, and reports.
- Implement an advanced search for invoices (by invoice number, member name/mobile, date range, activity, status).
- Add a customer data section (name, mobile, address) on the invoice creation screen, which is auto-filled from member data but can be edited for that specific invoice.
- Add a 15% VAT.
- Allow manual editing of the total amount on an invoice.
- Allow creating a new member directly from the invoice creation page.
- Add the academy logo, Tax ID (312655637900003), and Commercial Registration (7043630230) to the invoice.
- Add functionality to restore and delete invoices.
- Add a QR code to the electronic invoice.
- Add print buttons for reports and member data.
- Allow manual editing of subscription start and end dates.
- Ensure the invoice print view is a single page and reduce the logo size.
