## 🛠️ الطريقة الأولى: PWABuilder (الأسهل)

### الخطوات:

1. **افتح PWABuilder**
   - اذهب إلى: https://www.pwabuilder.com/

2. **أدخل رابط التطبيق**
   ```
   https://academy-manager-30.preview.emergentagent.com/portal
   ```

3. **اضغط "Start"**
   - سيتم فحص التطبيق تلقائياً

4. **اختر "Android"**
   - اختر "Google Play" كوجهة

5. **أكمل المعلومات**
   - Package Name: `com.gcsp.academy.portal`
   - App Name: `أكاديمية أداء الأبطال`
   - Version: `1.0.0`
   - Version Code: `1`

6. **حمّل ملف AAB**
   - سيتم إنشاء ملف `.aab` جاهز للرفع

## 📸 الصور المطلوبة لمتجر جوجل

### 1. أيقونة التطبيق (App Icon)
- الحجم: 512x512 بكسل
- الصيغة: PNG (32-bit, بدون شفافية)
- الملف: `/app/frontend/public/images/icon-512x512.png` ✅

### 2. Feature Graphic (صورة الميزة)
- الحجم: 1024x500 بكسل
- الصيغة: PNG أو JPG
- الملف: يجب إنشاؤه

### 3. لقطات الشاشة (Screenshots)
- الحد الأدنى: 2 لقطات
- الحد الأقصى: 8 لقطات
- الأحجام المطلوبة:
  - هاتف: 1080x1920 أو 1080x2160
  - تابلت 7 بوصة: 1200x1920
  - تابلت 10 بوصة: 1600x2560
