## Build Instructions

### Prerequisites
- Android Studio (latest version)
- JDK 17+

### Steps to Build APK/AAB

1. Open Android Studio
2. Open project: `frontend/android/`
3. Wait for Gradle sync to complete
4. Build > Generate Signed Bundle / APK
5. Choose Android App Bundle (AAB) for Google Play
6. Create/select keystore for signing
7. Build release version

### Important Notes
- The app connects to the live server for data
- Server URL is configured in `frontend/src/config/api.js`
- Before publishing, ensure the server is deployed permanently (use Replit Publish)
- Version code must be incremented for each Google Play update
