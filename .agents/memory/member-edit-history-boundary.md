---
name: Member edit-history scope
description: Keep staff audit history distinct from portal profile-change request history.
---

The admin's modified-member badge opens staff edit evidence, not the history of requests submitted by members through the portal.

**Why:** The user explicitly chose to review recorded staff changes, restricted to admins. Portal requests are a separate workflow and requested values are not proof that a change was applied.

**How to apply:** Show only recorded audit differences with their actor and time. Missing historical values must remain explicitly unavailable; never substitute the member's current profile or a pending request as an old/new value. Keep staff with ordinary member/phone access outside this admin-only history.
