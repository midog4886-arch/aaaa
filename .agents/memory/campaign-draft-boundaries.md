The proposed campaign send time is advisory, not an authorization for unattended sending.

**Why:** The reference labels this as a proposed time. Adding automatic delivery would change messaging and quota behavior beyond the requested draft-management feature.

**How to apply:** Keep actual delivery behind explicit confirmation; introduce a scheduler only with an explicit request and its own retry/deduplication safeguards.
